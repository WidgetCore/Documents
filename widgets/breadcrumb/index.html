Breadcrumb Widget

Full guide to the WidgetCore Breadcrumb widget: Yoast/Rank Math bridge, an internal trail from home, ancestors and categories, eight separators plus a custom one, JSON-LD schema and style controls.

Last updated 8 October 2026

The Breadcrumb widget shows the navigation chain of the current page: Home ← middle sections ← the current item. In automatic mode, if the Yoast SEO or Rank Math plugin is active, that plugin's own breadcrumb is printed (the SEO bridge); otherwise the widget builds the trail itself from the WordPress structure and can print the BreadcrumbList schema. The widget ships no JavaScript.

How the internal trail is built

Page typeCrumbs
PageHome ← page ancestors (top-down) ← page title
Single postHome ← primary category (optional) ← post title
Category/tag/taxonomy archiveHome ← term name
Author archiveHome ← author display name
Search resultsHome ← "Search: phrase"
404Home ← "Not found"
Post type archiveHome ← archive title
Front pageJust "Home" as the current crumb

HTML output

Class / rolePurpose
nav.wgcr-breadcrumbNavigation landmark with an aria-label
.wgcr-breadcrumb-listThe ordered ol list of crumbs
.wgcr-breadcrumb-itemEach crumb; the last one carries aria-current="page" and no link
.wgcr-breadcrumb-sepThe separator with aria-hidden="true" (screen readers skip it)
.wgcr-breadcrumb--bridgeThe wrapper around Yoast/Rank Math output in bridge mode

In the JSON-LD schema every crumb is a ListItem with position and name, and all crumbs except the current one carry an item URL — the pattern Google recommends.

Style sections

  • Box: background, border, radius, shadow and padding (the shared control library), typography, "Text color", "Current crumb color", "Layout" and "Space between crumbs".
  • Links and separator: "Link color" and "Separator color" in the Normal tab and "Link hover color" in the Hover tab. Colors run through CSS variables, so hover always works even when the Normal colors are set.

The SEO bridge

In Yoast/Rank Math mode the widget's own stylesheet is not loaded; the trail is styled entirely by the SEO plugin. Choose "Internal" mode for a fully uniform look.
