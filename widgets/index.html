Widgets

The list of WidgetCore widgets in Elementor, the name and purpose of each, the dedicated “WidgetCore Widgets” category and how assets are loaded only where needed.

Last updated 1 October 2026

WidgetCore adds its widget set to Elementor (3 widgets today). Every widget lives in the dedicated WidgetCore Widgets category so it never gets lost among the others, and each one has a complete guide on its own page of these docs.

Finding the widgets in the editor

  1. Open the page with Elementor

    Enter through “Edit with Elementor”.

  2. Search in the widget panel

    Type “WidgetCore” or wgcr in the panel's search field.

  3. Or open the category

    “WidgetCore Widgets” sits among the Elementor categories.

  4. Drag the widget

    Like any other widget, drop it into the section or column you want.

If the category is missing, Elementor is inactive or the editor cache is stale; hard-refresh the page (Ctrl + Shift + R).

Assets load only when needed

The widgets declare their style and script with get_style_depends() and get_script_depends():

WidgetStyleScript
FAQwgcr-faqwgcr-faq
Live Searchwgcr-searchwgcr-search
Commentswgcr-comments—

In practice this means a page without any WidgetCore widget loads no extra CSS or JS file. Inside the Elementor editor the assets are loaded through the elementor/preview/enqueue_styles and elementor/preview/enqueue_scripts hooks, so the preview matches the front end exactly.

Asset versions

Both files are registered with the plugin version number (WGCR_VER), that is search.css?ver=0.0.8. After every update the browser fetches the new file, so “stale styles” never happens.

Responsive sizes and hover

Every size control in the Style tab of all three widgets — widths and heights, padding, margins, gaps, corner radius, icon and avatar sizes — works in two dimensions:

  • Devices. Each control has the Elementor device switcher. Set a value for desktop, then a different one for tablet or mobile; a device without its own value inherits from the larger one. The breakpoints are the ones in Site Settings → Layout → Breakpoints.
  • States. Each control sits in Normal and Hover tabs. A hover value is applied only while the pointer is over the same element the normal value targets, and it can have its own tablet and mobile values. Leave the Hover tab empty and nothing is written for hover.

A widget you never touch writes no extra CSS. The speed of the FAQ animation, the rotation of the custom FAQ icon and the content-tab settings are not sizes and have neither switcher. Colours, borders, shadows and typography keep the states they already had (for example the normal/hover colours of the submit button); typography is responsive through Elementor's own switcher.
