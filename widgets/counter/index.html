Counter widget

The complete guide to the WidgetCore Counter widget — starting and ending numbers, animation duration, prefix and suffix, title and description, reduced motion and every style control.

Last updated 8 October 2026

The Counter widget animates a number from a starting value to an ending value — once, when the widget scrolls into view. It is built for stats like “1200 active students” or “98% satisfaction”.

Animation behaviour

  • The number in the HTML is the ending number from the start, so with JavaScript off the correct value is still shown and nothing is lost for crawlers.
  • The script waits with an IntersectionObserver (threshold 0.3) until the widget is visible, then counts from start to end with a cubic ease-out curve and sets data-done="1" when finished; the animation never runs twice — not even when the counter sits inside tabs and is shown and hidden repeatedly.
  • Without IntersectionObserver support the animation runs immediately.
  • With prefers-reduced-motion: reduce the ending number is written directly, without movement.
