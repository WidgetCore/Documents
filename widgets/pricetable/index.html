Price Table widget

The complete guide to the WidgetCore Price Table widget — plan name, featured plan and badge text, currency symbol, amount and period, the features list, the button and every style control.

Last updated 8 October 2026

The Price Table widget builds a complete plan card: the plan name, a price with a currency symbol and a period, a feature list with included/excluded marks and a call-to-action button. Great for course plans, subscriptions or service packages. The output is pure CSS with no JavaScript.

The “Features” section

The Features list (features) is a repeater with two fields:

FieldIDTypeDefaultNotes
Feature textfeature_textText“Plan feature”Rows with an empty text are dropped
Included in this planincludedSwitcherOnOff → the row gets the wgcr-pt-no class and a cross icon

Three sample rows are filled in from the start: two included features and one excluded feature.

The “Button” section

ControlIDTypeDefaultNotes
Button textbutton_textText“Enroll in the course”Empty means no button
Button linkbutton_linkURL#Invalid URLs are ignored; new tab and nofollow come from the URL control's own options

HTML output

ClassPurpose
.wgcr-pricetable-featuredThe featured plan state (visual emphasis of the card)
.wgcr-pt-badgeThe badge on top of the card
.wgcr-pt-name / .wgcr-pt-price / .wgcr-pt-cur / .wgcr-pt-amount / .wgcr-pt-periodPlan name and the price parts
.wgcr-pt-features / .wgcr-pt-feat / .wgcr-pt-noThe feature list and a not-included row
.wgcr-pt-icThe check or cross icon (inline SVG)
.wgcr-pt-btnThe call-to-action button

If the plan name, the amount, every feature and the button text are all empty, the widget prints nothing at all.

Style sections

  • Card: a ready-made box group (background, border, shadow, padding, radius) plus “Accent color” (button, badge and the featured outline).
  • Header and price: “Plan name color”, “Amount color”, “Currency and period color”, “Badge background”, “Badge text color” and the name/amount typographies.
  • Features list: “Feature text color”, “Included icon color”, “Not-included icon and text color” and “Gap between features”.
  • Button: “Button background” and “Button text color” in the Normal tab, “Button background on hover” and “Button text color on hover” in the Hover tab, the button typography, “Button padding” and “Button corner radius”. By default hover slightly brightens the normal color; setting “Button background on hover” turns that brightness effect off and applies your exact color.
