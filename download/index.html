Release package vs repository ZIP

The widgetcore.zip asset attached to each release is the plugin folder itself and installs directly in WordPress. The repository ZIP also contains other folders and a different plugin folder structure; for installation, always take the release asset.

What is inside the package

The widgetcore.zip package contains a single widgetcore/ folder with these files:

PathRole
widgetcore.phpMain file: plugin header, constants, category and widget registration
uninstall.phpRuns when the plugin is deleted (it removes no data)
readme.txtPlugin metadata and the changelog
LICENSEThe full GPL-2.0-or-later license text
widgets/class-faq-widget.phpThe FAQ widget
widgets/class-search-widget.phpThe live search widget
includes/search/search-shared.phpShared search logic and the shortcode
includes/search/rest-search.phpThe search REST route
includes/update/github-updater.phpUpdates from GitHub
assets/search/search.cssFront-end search styles
assets/search/search.jsFront-end search behaviour
languages/widgetcore-fa_IR.mo and .poPersian translation
languages/widgetcore-en_US.mo and .poEnglish translation
languages/widgetcore.potTranslation template for other languages
index.php in every folderProtects directories from being listed

There is no image, font or third-party library in the package; the plugin needs no extra asset to work.

Choosing the right version

  • Always take the latest release: versions are a simple counter (0.0.8) and every release contains the fixes of the previous ones.
  • On an older WordPress site: WordPress 6.7 and PHP 7.4 are the minimums — see requirements and compatibility.
  • Without Elementor: the plugin registers no widget unless Elementor is present, so install Elementor first.
