مسیرهای REST API

همه‌ی مسیرهای REST ویجت‌کور در یک صفحه؛ تنها مسیر عمومی جستجو، کاربردش، قاعده‌های مشترک، قابلیت‌هایی که اصلاً REST ندارند و روش سریع آزمایش آن.

آخرین به‌روزرسانی ۱۴۰۵/۰۷/۱۵

ویجت‌کور دقیقاً یک مسیر REST دارد: همان که ویجت جستجوی زنده و شورت‌کد [wgcr_search] برای گرفتن نتایج استفاده می‌کنند. این مسیر عمومی و مستند است؛ پس می‌توانید از جاوااسکریپت خودتان، اپلیکیشن موبایل یا افزونه‌ی دیگر صدایش بزنید. این صفحه همه‌ی مسیرها و قاعده‌های مشترکشان را فهرست می‌کند. مسیری که توضیح بلندتری لازم دارد، صفحه‌ی جدا زیر همین صفحه دارد.

همه‌ی مسیرهای REST

مسیرمتداستفاده‌کنندهدسترسیمرجع کامل
/wp-json/wgcr/v1/searchGETویجت جستجوی زنده، [wgcr_search]عمومی (بدون ورود، بدون nonce)مسیر REST جستجو

ویجت‌های دیدگاه‌ها و سوالات متداول مسیر REST ندارند. بخش قابلیت‌های بدون REST را ببینید.

قاعده‌های مشترک

  • فضای نام: همه‌ی مسیرهای ویجت‌کور زیر wgcr/v1 هستند. آدرس کامل https://example.com/wp-json/wgcr/v1/<route> است؛ بدون پیوند یکتای زیبا از https://example.com/?rest_route=/wgcr/v1/<route> استفاده کنید.
  • فقط خواندنی: مسیرها به GET پاسخ می‌دهند و JSON برمی‌گردانند. چیزی در پایگاه‌داده نوشته نمی‌شود و گزینه، کوکی یا متایی ساخته نمی‌شود.
  • فقط داده‌ی عمومی: نتایج فقط چیزی را شامل می‌شوند که هر بازدیدکننده‌ای به آن دسترسی دارد، مثل نوشته‌های منتشرشده‌ی بدون رمز. فیلترهای سفارشی سایت شما می‌توانند این را تغییر دهند؛ پس امنشان نگه دارید.
  • خطاها مثل وردپرس: درخواست ناموفق شیء خطای استاندارد REST را با code، message و data.status برمی‌گرداند.
  • بدون محدودیت نرخ: افزونه محدودیتی اضافه نمی‌کند. جدول بهینه‌سازی را در مرجع جستجو ببینید.
  • کش: کش REST باید بر اساس کل رشته‌ی کوئری جدا شود و هدرهای صفحه‌بندی را نگه دارد.

قابلیت‌های بدون REST

قابلیتبه‌جای آن چه می‌شود
ویجت دیدگاه‌ها و [wgcr_comments]فرم به wp-comments-post.php خود وردپرس ارسال می‌شود. اعتبارسنجی، بررسی اسپم و تأیید دستی را وردپرس انجام می‌دهد. افزونه هیچ کنترل‌کننده‌ی REST، AJAX یا admin-post اضافه نمی‌کند.
ویجت سوالات متداولصفحه روی سرور ساخته می‌شود و بعد از بارگذاری درخواستی نمی‌فرستد.

آزمایش کارکرد REST API

آرایه‌ی JSON یعنی مسیر کار می‌کند. اگر rest_cannot_access، خطای 404 یا صفحه‌ی خطا گرفتید، یک افزونه‌ی امنیتی، قانون سرور یا تنظیم پیوندهای یکتا REST API وردپرس را مسدود کرده است؛ عیب‌یابی و نیازمندی‌ها را ببینید.

صفحه‌های مرتبط

REST API جستجومرجع کامل مسیر REST جستجوی زنده؛ همه‌ی پارامترها، شکل پاسخ، هدرهای صفحه‌بندی، نمونه‌های curl و جاوااسکریپت و نکات امنیتی. ویجت جستجوی زندهراهنمای کامل ویجت جستجوی زنده‌ی WidgetCore؛ کنترل‌های عمومی، طرح‌بندی، کوئری و صفحه‌بندی، ساختار خروجی، رفتار جاوااسکریپت و کار بدون جاوااسکریپت. ویجت دیدگاه‌هاراهنمای کامل ویجت دیدگاه‌های WidgetCore؛ فهرست دیدگاه‌ها و فرم ثبت برای نوشتهٔ جاری، روشن و خاموش‌کردن نام، ایمیل و وب‌سایت، اجباری یا اختیاری‌کردن فیلدها، ترتیب فیلدها، صفحه‌بندی، آواتار، شورت‌کد و استایل‌دهی.
