What is WidgetCore?

An introduction to the WidgetCore plugin for Elementor — accessible widgets: an FAQ accordion with FAQPage schema, an AJAX live search and a comments widget, with requirements and a reading path.

Last updated 2026-09-26

WidgetCore is a free, open-source WordPress plugin that adds a growing set of practical, ready-to-use widgets to Elementor — including an accessible FAQ accordion that outputs FAQPage structured data, a live search that shows results without reloading the page, also available anywhere on the site through the [wgcr_search] shortcode, and a comments widget with a list and a configurable form ([wgcr_comments]). Every widget the plugin ships has its own guide page in these docs, and the set grows with each release.

The plugin focuses on three things: real accessibility (keyboard support, ARIA and reduced motion), first-class Persian and right-to-left support (with fa_IR and en_US translations bundled), and staying light (no external JavaScript or CSS library, no requests of its own beyond the update check).

Suggested reading path

  1. Check the requirements

    WordPress 6.7 or newer, PHP 7.4 or newer, and an active Elementor installation. Details on the requirements page.

  2. Download and install the plugin

    Get the ZIP package from the download page and activate it following the installation guide.

  3. Place your first widget

    In the Elementor editor, open the “WidgetCore Widgets” category and drag a widget onto the canvas.

  4. Configure the behaviour

    For search, read display modes and pagination; for FAQs, see the FAQ widget page.

  5. Stay current

    Updates are delivered straight from the GitHub repository — see the updates page.

How the plugin is organised

The plugin is a handful of small, independent parts. Knowing them makes troubleshooting much faster:

PartRole
widgetcore.phpRegisters the widget category, loads translations and registers assets
widgets/class-faq-widget.phpThe FAQ widget with its inline style and script
widgets/class-search-widget.phpThe live search widget and all of its controls
includes/search/search-shared.phpShared search logic, the shortcode and the render output
includes/search/rest-search.phpThe search REST route and its parameters
widgets/class-comments-widget.phpThe comments widget and its controls
includes/comments/Shared comments logic, the shortcode and the signed-field policy for required fields
includes/update/github-updater.phpUpdates from the GitHub repository
assets/search/search.css and search.jsFront-end appearance and behaviour of the search widget
assets/comments/comments.cssFront-end appearance of the comments widget (no script)
languages/The fa_IR and en_US translation files and the .pot template

What the plugin does not do

  • No external JavaScript or CSS library is loaded; everything ships inside the package.
  • No data is sent to a third-party server by the plugin. Its own network requests are to your own WordPress REST API and (when checking for updates) to the GitHub API. The one thing to know: if avatars are shown in the Comments widget, WordPress loads them from Gravatar in the visitor's browser; set the widget's “Avatar” to “Hide” to avoid it.
  • Widgets are registered inside Elementor only; with Elementor inactive, the plugin adds nothing to your site.
