Installation and activation

Step-by-step installation of WidgetCore in WordPress using three methods (ZIP upload, FTP and WP-CLI), activation, verifying the widgets in Elementor and removing the plugin.

Last updated 2026-09-26

Installing the plugin is exactly like installing any other WordPress plugin. This page covers three methods, how to verify the result and what deleting the plugin does.

Method 1 — Upload from the dashboard (recommended)

  1. Download the package

    Get widgetcore.zip from the download page. Do not unzip it.

  2. Go to the plugins screen

    In the WordPress dashboard: “Plugins → Add New”, then the “Upload Plugin” button at the top.

  3. Choose the file and install

    Select the ZIP file and click “Install Now”.

  4. Activate

    After the install finishes, click “Activate Plugin”.

Method 2 — Manual copy over FTP or a file manager

  1. Unzip the package

    You get a widgetcore/ folder.

  2. Put the folder in wp-content/plugins/

    The final path must be wp-content/plugins/widgetcore/widgetcore.php.

  3. Activate the plugin

    Click “Activate” on the Plugins screen.

A common manual-install mistake

If the path ends up as wp-content/plugins/widgetcore/widgetcore/widgetcore.php, the plugin will not appear in the list. Remove one folder level so that widgetcore.php sits directly inside widgetcore/.

Method 3 — WP-CLI

If Elementor is installed but inactive, activate it as well:

The plugin creates no database table, stores no option and adds no media file.

Verifying the installation

  1. See the widgets in Elementor

    Open a page with Elementor; the “WidgetCore Widgets” category with the plugin's widgets should be in the panel.

  2. Test the REST route

    Open https://example.com/wp-json/wgcr/v1/search?q=test&limit=2; a JSON array should come back.

  3. Check the version

    On the Plugins screen, WidgetCore should show version 0.0.8.

If any of these fails, see the troubleshooting page.

Deactivating and deleting

  • Deactivation: the widgets disappear from the editor and no asset is loaded. Pages built with these widgets keep their saved Elementor content but render no output on the front end.
  • Deletion: the plugin's uninstall.php is intentionally empty, so deleting the plugin removes no data — because the plugin stores no data of its own. Widget settings live inside each page's Elementor content and keep working after a reinstall.

Quick recovery

Because the plugin stores no data, deleting and reinstalling it is completely safe and is the first suggested fix for most problems.

Installing on a multilingual site

The plugin is not multilingual by itself; interface texts follow the current WordPress locale (determine_locale()). If you use a multilingual plugin:

  • Place a separate search widget per language and set its Source to the post type used by that language.
  • For a custom translation, put your .mo file in wp-content/languages/plugins/; that path takes precedence over the bundled translation (full explanation on the language and translation page).
